
# Smart Local Tourism Business Portal

## About the Project
Smart Local Tourism Business Portal is a beginner-friendly web development project that promotes local tourism in Karnataka.

It helps visitors explore tourist destinations, village festivals and cultural attractions in Shivamogga and Udupi.

## Objectives
- Promote local tourism.
- Display popular tourist destinations.
- Introduce Karnataka village festivals.
- Help visitors discover local attractions.
- Provide a simple contact enquiry form.

## Technologies Used
- HTML
- CSS
- JavaScript

## Main Features
1. Attractive home page.
2. Tourist places information.
3. Search tourist destinations.
4. Category filter for Shivamogga and Udupi.
5. Karnataka village culture and festivals.
6. Contact enquiry form.
7. Responsive design for mobile and desktop.

## Tourist Places Covered

### Shivamogga
- Jog Falls
- Agumbe
- Kundadri Hills
- Sakrebailu Elephant Camp

### Udupi
- Malpe Beach
- Kaup Lighthouse
- St Mary's Island
- Udupi Krishna Temple

## Karnataka Village Culture

- Kambala
- Village Dasara
